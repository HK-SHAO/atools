# 项目整理

## 目标与边界

atools 在浏览器本地把音频编码成频谱图片，并从图片合成单声道音频。紧凑模式舍弃相位以减小图片，可逆模式保存量化后的幅度和相位。它不是通用无损音频压缩器；采样率、频宽、裁剪、声道合并和图片编辑都会影响还原结果。

前端由 Bun 安装、开发、测试和打包；React 管理交互，Web Worker 承担数值与图片处理，MoonBit 编译成 Wasm 内核。TypeScript 和 Oxlint 分别负责类型检查与静态检查。

## 里程碑

1. 验证入口可移植，记录初始基线。
2. 审查异步任务、取消、错误恢复、资源生命周期和 PWA 隔离；补有实际失败场景的回归验证。
3. 审查算法与 Wasm 边界，和 main 进行同口径质量及性能比较。
4. 清理历史叙述、实验残留和重复代码，修正文档承诺，补齐公开开发与验证说明。
5. 完整验证构建、音质、性能、界面、离线与干净检出流程。

每个完成的里程碑独立提交；未验证的改善不记为完成。

## 已完成

- 验证入口：移除浏览器个人绝对路径，支持 `CHROME`、PATH 和常见安装目录。Chrome 实际界面链通过，页面零异常、采样期间零长任务。
- PWA 缓存隔离：缓存名包含 Service Worker 路径与构建版本，仅清理该路径的旧版本；读取限定当前缓存，后台写入计入事件生命周期。三项回归测试覆盖其他应用缓存保留、当前缓存读取、离线首页；生产构建与真实浏览器离线检查通过。旧版无路径标识的缓存不自动删除，因为无法可靠判断所属部署。
